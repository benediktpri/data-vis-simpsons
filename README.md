# Data Visualization Project — The Simpsons

Data Visualization course project at FIB, Universitat Politecnica de Catalunya (UPC).

**Authors:** Benedikt Prisett & Stijn Diemel

**Source data:** [The Simpsons Dataset](https://www.kaggle.com/datasets/prashant111/the-simpsons-dataset) on Kaggle

## Setup

This project uses [uv](https://docs.astral.sh/uv/) for dependency management with Python 3.13.

```bash
uv sync
```

## Technologies

- **[Altair](https://altair-viz.github.io/)** (Vega-Lite) for visualizations
- **[Streamlit](https://streamlit.io/)** for interactive dashboards
- **[pandas](https://pandas.pydata.org/)** for data processing
